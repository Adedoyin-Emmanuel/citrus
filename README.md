# Citrus

A small macOS menu bar app that makes your images and videos smaller. Built by Adedoyin Emmanuel Adeniyi.

Drop your files in, pick how small you want them (Smaller, Balanced, or Best Quality), and hit Compress. Citrus figures out the rest.

It uses Apple's built-in media frameworks, so there's no FFmpeg and nothing extra to install.

## Install

```bash
cd app
./Scripts/install.sh
```

After that, just type `citrus` in your terminal to open it. Run the script again whenever you pull new changes.

## Development

```bash
cd app
swift run
```

Notifications only show up when you run the installed app, not with `swift run`.
